TinyNPU
End-to-End Deep Learning Hardware Accelerator Architecture
Complete Engineering, Mathematical & FPGA Synthesis Reference Manual
Author: Pranav Kamble | Verified Production Edition (Phases 1 – 9 Complete)
Executive Summary: TinyNPU bridges machine learning algorithm design with digital silicon logic design. It demonstrates how a 3-layer Multilayer Perceptron (MLP) trained in Python is quantized into INT8/INT32 integer arithmetic, translated into synthesizable SystemVerilog RTL, and implemented across multiple FPGA hardware architectures (Combinational, 3-Cycle Sequential FSM, Pipelined Streaming, and Ultra-Low-Area 1-MAC Resource-Shared) with 100% bit-accurate verification.

1. High-Level Project Motivation & Problem Statement

Modern Artificial Intelligence workloads running on standard Central Processing Units (CPUs) and Graphics Processing Units (GPUs) suffer from severe energy inefficiencies when executing inference on edge devices (drones, wearable medical sensors, automotive controllers):

  • Instruction Overhead: Von-Neumann processors spend >90% of total energy fetching, decoding, and managing instruction caches rather than computing matrix dot-products.
  • Floating-Point Penalty: Standard IEEE-754 32-bit floating-point arithmetic (FP32) consumes massive silicon area and power ($>500$ LUTs per FP multiplier).
  • Memory Bandwidth Bottleneck: Fetching 32-bit weights from external DRAM creates thermal and latency bottlenecks.

The Solution: A specialized Neural Processing Unit (NPU) that executes low-power integer arithmetic (INT8 weights, INT32 accumulators), stores weights in local on-chip Block RAMs (BRAM), and hardwires neural computation directly in digital silicon logic.

2. Neural Network Topology & Mathematics

2.1 Architecture Specification

The network is configured as a binary classification Multilayer Perceptron (MLP): 21 → 14 → 7 → 1

  • Input Layer: 21 Features ($\mathbf{x} \in \mathbb{R}^{21 \times 1}$)
  • Hidden Layer 1: 14 Neurons + ReLU ($\mathbf{W}^{(1)} \in \mathbb{R}^{14 \times 21}$, $\mathbf{b}^{(1)} \in \mathbb{R}^{14 \times 1}$) → 294 weights, 14 biases
  • Hidden Layer 2: 7 Neurons + ReLU ($\mathbf{W}^{(2)} \in \mathbb{R}^{7 \times 14}$, $\mathbf{b}^{(2)} \in \mathbb{R}^{7 \times 1}$) → 98 weights, 7 biases
  • Output Layer: 1 Neuron + Sigmoid ($\mathbf{W}^{(3)} \in \mathbb{R}^{1 \times 7}$, $b^{(3)} \in \mathbb{R}$) → 7 weights, 1 bias
  • Total Parameters: 399 Weights + 22 Biases = 421 Trainable Parameters

2.2 Forward Propagation Calculus

$$\mathbf{z}^{(1)} = \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}, \qquad \mathbf{h}^{(1)} = \text{ReLU}(\mathbf{z}^{(1)}) = \max(0, \mathbf{z}^{(1)})$$ $$\mathbf{z}^{(2)} = \mathbf{W}^{(2)}\mathbf{h}^{(1)} + \mathbf{b}^{(2)}, \qquad \mathbf{h}^{(2)} = \text{ReLU}(\mathbf{z}^{(2)}) = \max(0, \mathbf{z}^{(2)})$$ $$z^{(3)} = \mathbf{W}^{(3)}\mathbf{h}^{(2)} + b^{(3)}, \qquad \hat{y} = \sigma(z^{(3)}) = \frac{1}{1 + e^{-z^{(3)}}}$$ $$\text{Class Prediction} = \begin{cases} 1 & \text{if } \hat{y} \ge 0.5 \iff z^{(3)} \ge 0 \\ 0 & \text{if } \hat{y} < 0.5 \iff z^{(3)} < 0 \end{cases}$$

2.3 Binary Cross-Entropy Loss & Backpropagation Equations

$$\mathcal{L}(y, \hat{y}) = -\left[ y \ln(\hat{y} + \epsilon) + (1 - y) \ln(1 - \hat{y} + \epsilon) \right]$$
  1. Output Layer Error: $\delta^{(3)} = \frac{\partial \mathcal{L}}{\partial z^{(3)}} = \hat{y} - y, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(3)}} = \delta^{(3)}(\mathbf{h}^{(2)})^T, \quad \frac{\partial \mathcal{L}}{\partial b^{(3)}} = \delta^{(3)}$
  2. Hidden Layer 2 Error: $\boldsymbol{\delta}^{(2)} = [(\mathbf{W}^{(3)})^T \delta^{(3)}] \odot \mathbb{I}(\mathbf{z}^{(2)} > 0), \quad \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(2)}} = \boldsymbol{\delta}^{(2)}(\mathbf{h}^{(1)})^T, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{b}^{(2)}} = \boldsymbol{\delta}^{(2)}$
  3. Hidden Layer 1 Error: $\boldsymbol{\delta}^{(1)} = [(\mathbf{W}^{(2)})^T \boldsymbol{\delta}^{(2)}] \odot \mathbb{I}(\mathbf{z}^{(1)} > 0), \quad \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(1)}} = \boldsymbol{\delta}^{(1)}\mathbf{x}^T, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{b}^{(1)}} = \boldsymbol{\delta}^{(1)}$
  4. Gradient Descent Update: $\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L} \quad (\eta = 0.01)$

3. Quantization & Fixed-Point Arithmetic

3.1 Affine Symmetrical INT8 Quantization

$$S = \frac{\max(|X|)}{127}, \qquad q = \text{clip}\left(\left\lfloor \frac{x}{S} \right\rceil, -128, 127\right), \qquad x \approx \tilde{x} = q \times S$$

3.2 Why Accumulators and Biases Require INT32

Multiplying two signed INT8 numbers results in an INT16 product ($-16384 \dots +16384$). Accumulating 21 products expands the dynamic range by $\log_2(21) \approx 4.4$ bits ($16 + 5 = 21$ bits). Standard signed 32-bit accumulators (`logic signed [31:0]`) are used to guarantee zero overflow in silicon:

$$b_{\text{int32}} = \left\lfloor \frac{b_{\text{fp32}}}{S_{\text{in}} \cdot S_w} \right\rceil$$

3.3 Dyadic Fixed-Point Scaling (Eliminating Division in Silicon)

Converting the INT32 accumulator to an INT8 activation requires multiplying by the scale ratio $M = \frac{S_{\text{in}} \cdot S_w}{S_{\text{out}}}$. Instead of expensive floating-point hardware division, we approximate $M$ using dyadic fixed-point scaling with a 20-bit shift:

$$\text{MULTIPLIER} = \left\lfloor M \cdot 2^{20} \right\rceil, \qquad \text{output} = (\text{accumulator} \times \text{MULTIPLIER}) \ggg 20$$
